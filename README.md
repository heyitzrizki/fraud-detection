# RiskLens AI: Explainable Fraud & Risk Intelligence Platform

RiskLens AI is an MVP fraud risk intelligence platform built with the IEEE-CIS Fraud Detection dataset. It turns fraud model scores into threshold decisions, risk explanations, and an analyst-ready alert queue.

## Project Overview

The project covers a compact end-to-end workflow: exploration, feature engineering, time-based validation, LightGBM modeling, threshold optimization, SHAP-based explanations, and a React web dashboard for fraud decisioning.

## Business Problem

Fraud detection is not only a classification problem. A useful workflow must balance fraud capture, false positives, investigation workload, and cost. Accuracy is not the main metric because fraud is rare.

The project focuses on one question: which transactions should be reviewed first, why were they flagged, and what happens when the alert threshold changes?

## Dataset

This MVP uses the IEEE-CIS Fraud Detection dataset. The workflow uses `train_transaction.csv` only, placed at:

```text
data/raw/train_transaction.csv
```

The optional `train_identity.csv` file can also be stored in `data/raw/`, but it is not used in the MVP model.

## MVP Features

- Fraud risk scoring
- Time-based validation
- Cost-sensitive threshold optimization
- SHAP explainability
- Alert queue
- Template-based analyst notes
- React web dashboard with Decisioning, Alerts, and System explanation views
- Legacy Streamlit dashboard retained in `app.py`

## How to Run

Install Python dependencies for notebook/model work:

```bash
pip install -r requirements.txt
```

Launch the React web app with the included model outputs:

```bash
cd web
npm install
npm run dev
```

The React app reads these generated files from `outputs/`:

```text
outputs/metrics_summary.json
outputs/threshold_results.csv
outputs/fraud_alert_queue.csv
```

The legacy Streamlit dashboard can still be launched with:

```bash
streamlit run app.py
```

To reproduce the workflow or refresh the model artifacts, place the dataset in `data/raw/` and run:

```bash
jupyter notebook notebooks/01_risklens_ai_mvp.ipynb
```

## Business Interpretation

RiskLens AI helps fraud analysts move from model scores to review decisions. The dashboard shows the trade-off between fraud capture and alert workload, while the alert queue provides risk level, top drivers, recommended action, and analyst notes. The System view explains how the dataset, model, threshold policy, SHAP reasons, and alert queue fit together.

Risk levels use the recommended threshold as the alert boundary:

- High: risk score >= 0.75
- Medium: risk score >= recommended threshold and < 0.75
- Low: risk score < recommended threshold

## Limitations

- Uses `train_transaction.csv` only
- Identity data is not used yet
- Test data is not used because labels are unavailable
- Cost assumptions are simplified
- React app uses static generated outputs; live inference needs an API layer
- Not production-ready
